# cc-skills

Скиллы для Claude Code.

## Установка

```bash
git clone https://github.com/h3llb0ys/cc-skills.git
cp -R cc-skills/skills/<имя> ~/.claude/skills/
```

## Скиллы

### consilium

Совет консольных агентов для внешнего ревью и выработки решений: codex CLI (GPT),
Claude-сабагенты, cursor-agent (grok). Два режима — ревью артефакта (код, архитектурное решение,
план, спека) и дизайн-совет, где участники предлагают решения, перекрёстно ревьюят и итеративно
улучшают выбранное.

Кроме механики запуска описывает протокол цикла целиком: сбор требований до старта участников,
проверку утверждений по коду, раунды верификации и совещание до консенсуса, адвоката дьявола
и премортем, кворум в финале, ревью итогового документа и сборку пакета передачи.

#### Что можно попросить

| Формулировка | Что запускается | Цена |
|---|---|---|
| «проревьюй через codex» | один участник, без раундов | 1 вызов, 5–15 мин |
| «консилиум», «второе мнение» | 3 участника параллельно (GPT + GPT + Claude) и сведённый вердикт | 3 вызова, 10–15 мин |
| «консилиум с xhigh», «добавь grok» | тот же цикл, другой состав или уровень reasoning | 3–4 вызова |
| «полный консилиум», «пусть проверят друг друга» | плюс раунд верификации: свежие сессии голосуют по анонимным находкам, галлюцинации отсеиваются | ×2 вызова |
| «пусть обсудят», «до консенсуса» | плюс совещание: живые сессии участников, адресные вопросы, снятие противоречий | +до 3 итераций |
| «с адвокатом дьявола» | плюс атака на консенсус моделью другого вендора — общее слепое пятно совета | +1 вызов |
| «с премортемом» | плюс сценарии провала решения через полгода (для архитектуры и планов) | +1 вызов |
| «дизайн-консилиум», «пусть предложат решения» | участники предлагают решения, перекрёстно ревьюят, выбирают лучшее и дорабатывают | часы |

Комбинируются свободно: «консилиум с xhigh, с адвокатом и премортемом», «дизайн-консилиум
в 10 раундов». Что не названо явно — скилл уточнит вопросом.

```
skills/consilium/
├── SKILL.md                     # хаб: модели, каркас вызова, ревью кода и документов
├── references/
│   ├── chair.md                 # роль председателя: требования, факты, лог, чекпоинты
│   ├── council.md               # состав, участники трёх вендоров, адвокат дьявола
│   ├── deliberation.md          # раунды, совещание, премортем, эскалация
│   ├── design.md                # дизайн-совет: этапы 0–5
│   └── finalization.md          # кворум, ревью документа, пакет передачи
└── scripts/
    ├── codex-run.sh             # запуск codex-участника (read-only, промпт из файла)
    └── cursor-run.sh            # запуск cursor-участника (grok)
```

Требуется установленный `codex` CLI; `cursor-agent` — для участников на grok.
