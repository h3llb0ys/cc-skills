# cc-skills

Скиллы для Claude Code.

## Установка

```bash
git clone https://github.com/h3llb0ys/cc-skills.git
cp -R cc-skills/skills/<имя> ~/.claude/skills/
```

## Скиллы

### consilium

Совет консольных агентов для внешнего ревью и выработки решений: codex CLI (GPT),
Claude-сабагенты, cursor-agent (grok). Два режима — ревью артефакта (код, архитектурное решение,
план, спека) и дизайн-совет, где участники предлагают решения, перекрёстно ревьюят и итеративно
улучшают выбранное.

Кроме механики запуска описывает протокол цикла целиком: сбор требований до старта участников,
проверку утверждений по коду, раунды верификации и совещание до консенсуса, адвоката дьявола
и премортем, кворум в финале, ревью итогового документа и сборку пакета передачи.

```
skills/consilium/
├── SKILL.md                     # хаб: модели, каркас вызова, ревью кода и документов
├── references/
│   ├── chair.md                 # роль председателя: требования, факты, лог, чекпоинты
│   ├── council.md               # состав, участники трёх вендоров, адвокат дьявола
│   ├── deliberation.md          # раунды, совещание, премортем, эскалация
│   ├── design.md                # дизайн-совет: этапы 0–5
│   └── finalization.md          # кворум, ревью документа, пакет передачи
└── scripts/
    ├── codex-run.sh             # запуск codex-участника (read-only, промпт из файла)
    └── cursor-run.sh            # запуск cursor-участника (grok)
```

Требуется установленный `codex` CLI; `cursor-agent` — для участников на grok.
