# Mattermost для BB

Плагин подключает общий [скилл Mattermost](../../skills/mattermost/SKILL.md) к тредам BB.
Для локальной установки из корня клона:

```sh
npm ci --prefix bb/mattermost
bb plugin build bb/mattermost
bb plugin install bb/mattermost
```

Открой новый тред и напиши «прочитай ветку» или «следи за веткой» со ссылкой
на сообщение. Для доступа нужны HTTPS-адрес Mattermost и сессионная cookie.
При первом подключении скилл предложит ввести их через форму секретов BB.

Для подписки BB покажет карточку вопросов, если она доступна у провайдера.
Скрипт проверяет ветку с выбранным интервалом, а агент присылает подходящие
обновления в заданный BB-тред. Для push включи нужный канал уведомлений в BB.
Проверки требуют работающего BB-сервера с доступом к Mattermost и Python 3.9+.
Вне BB тот же скилл задаёт вопросы текстом и поддерживает расписание Orca.

В панели **Mattermost** видны подписки BB списком или по тредам. Название открывает
чат BB, ↗ предлагает веб-версию или приложение Mattermost, ⚙ открывает условия
подписки. Внутри чата те же подписки доступны в сворачиваемом виджете.

Кнопка **Цвета** задаёт общую палитру. Красная точка означает, что владелец
должен ответить, оранжевая отмечает важное обновление, зелёная — решённый вопрос.
Та же метка видна у уведомления в чате BB. У обычных подписок метки нет. Список перечитывается каждые 30 секунд, пока виден.
Панель работает с БД на машине BB-сервера. Если планировщик использует специальный
`MM_STATE_DIR`, укажи тот же абсолютный каталог в настройках плагина.

Для запуска тестов и проверки типов установи зависимости общего компонента палитры
командой `npm ci --prefix bb/shared-ui` из корня клона.
