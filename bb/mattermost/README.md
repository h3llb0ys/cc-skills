# Mattermost для BB

Плагин подключает общий [скилл Mattermost](../../skills/mattermost/SKILL.md) к тредам BB.
Для локальной установки из корня клона:

```sh
npm ci --prefix bb/mattermost
bb plugin build bb/mattermost
bb plugin install bb/mattermost
```

Открой новый тред и напиши «прочитай ветку» или «следи за веткой» со ссылкой
на сообщение. Для доступа нужны HTTPS-адрес Mattermost и сессионная cookie.
В настройках плагина открой **Подключение к Mattermost**, введи адрес сервера
и значение заголовка Cookie. **Проверить соединение** запрашивает текущего
пользователя Mattermost с введёнными данными и показывает его имя. Нажми
**Сохранить**, чтобы скилл и расписания на этой машине использовали подключение.
Для проверки сохранённого подключения оставь поле Cookie пустым. При смене
адреса введи cookie заново.

Для подписки BB покажет карточку вопросов, если она доступна у провайдера.
Скрипт проверяет ветку с выбранным интервалом, а агент присылает подходящие
обновления в заданный BB-тред. Для push включи нужный канал уведомлений в BB.
Проверки требуют работающего BB-сервера с доступом к Mattermost и Python 3.9+.
Вне BB тот же скилл задаёт вопросы текстом и поддерживает расписание Orca.

В панели **Mattermost** видны подписки BB списком или по тредам. Название открывает
чат BB, основная кнопка открывает Mattermost по настройке плагина, стрелка рядом даёт выбрать браузер или приложение, кнопка с двумя ползунками открывает условия
подписки. Виджет чата сразу показывает все его подписки. В **Настройки → Плагины → Mattermost → Виджет в треде** выбери «С контекстом», «Одна строка» или «По каналам». В контекстном режиме вторая строка показывает открытый личный вопрос, непрочитанную сводку или ошибку. Последняя сводка доступна через меню «···» после прочтения и после проверки без изменений. «Входящие» внутри треда показывает вопросы его подписок.
«История сводок» хранит уведомления и черновики в порядке доставки. Открытие сводки отмечает её прочитанной. Раздельная кнопка открывает конкретное сообщение в Mattermost.
Корзина рядом с настройками удаляет выбранную подписку и её автоматизацию BB после подтверждения. История сводок сохраняется.
«Подписки» открывает условия и выбор доставки в чат или общий сабтред. Сабтред создаётся
при первой сводке. История сохраняется с момента обновления плагина.

В правой карточке треда и во вкладке **Info** видны его каналы и ветки, статус и время последней успешной проверки Mattermost. Раздельная кнопка открывает источник. Настройка **Показывать подписки в правой панели** управляет обеими секциями.

Общая палитра настраивается в **Настройки → Плагины → Mattermost → Цвета статусов**. По умолчанию красная точка означает, что владелец
должен ответить, оранжевая отмечает важное обновление, зелёная — решённый вопрос.
Та же метка видна у уведомления в чате BB. У обычных подписок метки нет. Список перечитывается каждые 30 секунд, пока виден.
Панель работает с БД на машине BB-сервера. Если планировщик использует специальный
`MM_STATE_DIR`, укажи тот же абсолютный каталог в настройках плагина.

Для запуска тестов и проверки типов установи зависимости общего компонента палитры
командой `npm ci --prefix bb/shared-ui` из корня клона.

Во **Входящих** собраны отдельные вопросы и важные обновления всех подписок BB.
Открытие карточки помечает её прочитанной. Когда в Mattermost отвечают на вопрос,
он переходит в свёрнутую группу «Решено». Если подписка запрашивает черновик,
кнопка «Показать черновик» открывает редактор. После копирования BB открывает исходное сообщение.
Во вкладке **Подписки** нажми **+**, вставь ссылку на канал или ветку и выбери тред BB для сводок. Кнопка **Создать подписку** включает расписание. Первый запуск разбирает существующий вопрос и ответы в ветке или всю доступную переписку канала. Затем проверки идут с выбранным интервалом. Если BB не смог создать расписание, нажми **Включить расписание** у сохранённой подписки. Здесь можно проверить конкретный источник сразу, изменить условия
либо поставить подписку на паузу, возобновить или удалить вместе с расписанием.
На паузе источник серый. При возобновлении BB запускает фоновую проверку с последней обработанной позиции.
Карточка во «Входящих» сохраняется, пока хотя бы одна активная подписка следит за этим сообщением. История сводок остаётся в её BB-треде.

Пока открыта панель Mattermost, левый сайдбар показывает все подписки BB. В **Настройки → Плагины → Mattermost → Список подписок** можно выбрать плоский список, группировку по статусам или по тредам BB и увидеть результат на демоданных. Нажатие на подписку следует настройке «При нажатии на подписку». Возврат на Главную восстанавливает обычную панель BB.
