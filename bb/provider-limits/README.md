# Provider Limits

Иконки провайдеров с кольцами оставшегося лимита внизу левой панели BB, над Settings. При наведении или фокусе — остаток, использование и дата сброса в локальном часовом поясе.

## Установка

[Установка и обновление из GitHub или локального клона](../README.md).

Выбрать Settings → Appearance → Navigation → Provider Limits, если BB не выбрал его автоматически. Настройки: Plugins → Provider Limits → Лимиты провайдеров.

- Интервал запросов к провайдерам: 0,5–1440 минут, по умолчанию 30 минут. Общий серверный кеш объединяет запросы всех окон BB.
- После сброса окна выполняется внеочередной запрос; после ошибки повторяем не позднее чем через минуту плюс до 30 секунд опроса интерфейса.
- Размер иконок вместе с кольцами: 28–44 px, по умолчанию 36 px.
- Отдельное включение провайдеров и выбор доступных периодов. «Все периоды автоматически» включает новые окна при появлении.
- У Claude порядок выбранных колец снаружи внутрь: Weekly limit → Current session → остальные периоды. Если выбраны оба основных периода, внешнее кольцо — недельное, внутреннее — 5-часовое. У остальных провайдеров сохраняется порядок ответа BB. 100% означает полный остаток, 0% — исчерпанный лимит.
- По умолчанию показаны только провайдеры со статусом `ok` и выбранными окнами. Ошибки, истёкший вход и отсутствующие лимиты видны в настройках. Отключение фильтра позволяет показывать статусы без заполненного кольца.
- Истёкшее окно не заменяется выдуманными 100%: ждём ответа провайдера. При временной ошибке сохраняются последние данные этого провайдера с предупреждением и временем их получения.

Основной источник квот — публичный `bb.sdk.system.usageLimits`. Для Antigravity CLI (`acp-antigravity-cli`), если BB не возвращает запись, плагин получает окна Gemini командой `agy -p /usage --output-format json`. Нужны установленный `agy` с поддержкой этой команды и действующий вход в CLI.

Данные относятся к машине сервера BB. Плагин работает с квотами из SDK и CLI, снимок лимитов живёт только в памяти. Обновление происходит, пока открыта панель или настройки плагина.

Плагин предоставляет свой вариант rail-навигации через SDK, сохраняет порядок и видимость пунктов BB и не меняет список тредов. Возврат: Settings → Appearance → Navigation → Rail; либо отключить плагин.

```sh
npm run typecheck
npm test
npm run build
bb plugin rpc call provider-limits snapshot --json
bb plugin rpc call provider-limits options --json
```
