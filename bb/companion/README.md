# Companion для BB

Плагин анализирует события треда после основного ответа, без постоянного вызова
модели. Он замечает коррекции, просьбы запомнить, существенные правки, коммиты,
ревью, внешние факты Grafana/Krisp и работу после свёртки контекста. Плановая
проверка срабатывает после пяти содержательных сообщений, аудит правил — не чаще
раза в 14 дней. Обычные сигналы объединяются в одну проверку с паузой в десять
минут. Явная коррекция не ждёт этой паузы.

Если агент предложил улучшения, над полем ввода появляется компактная карточка.
Она разворачивается по клику. Видны название, назначение и описание каждого
пункта. «Свой пункт» добавляет предложение, «×» убирает отдельный пункт,
«Отложить» сворачивает карточку и сохраняет текущий выбор между открытиями карточки.
«Применить» передаёт агенту только выбранное, карточка убирает пункты после
подтверждения результата. «Очистить» удаляет предложения после подтверждения.
Пустая карточка не отображается.

Проверка ничего не записывает в Companion. Хранятся только счётчики, состояние
проверки и краткие предложения. Применение соблюдает разрешения текущего треда
и не меняет код обслуживаемых сервисов.

## Установка

Из каталога плагина: `npm ci --include=dev`, `bb plugin build .`,
`bb plugin install .`. Затем укажи абсолютный путь к Companion:

```sh
bb plugin config companion set companionRoot /absolute/path/to/companion
```

В `projectIds` можно указать ID через запятую. Пустое значение включает проверку
во всех проектах BB. Без `companionRoot` проверки отключены. Для удалённого
провайдера путь Companion должен быть доступен агенту на его машине.

## Передача проверки от Codex

Без передачи ответственности проверки в Codex выполняют существующие хуки.
Плагин запускает автоматическую проверку в Codex только после подтверждения от
обёртки для конкретного хода. Для других провайдеров обёртка не нужна.

Чтобы BB полностью брал проверку на себя, на общей локальной машине BB и Codex
задать `handoffDirectory` (например, абсолютный путь к `tmp/bb-checkpoints`
в Companion) и в вызове **Companion Stop** в глобальном и, если применимо, локальном
`hooks.json` вставить перед существующей командой:

```text
python3 /absolute/path/to/cc-skills/bb/companion/codex-hook.py /absolute/path/to/lease-directory <исходная команда>
```

Следом подтвердить доверие к изменённому определению в Codex. Сигналы для
нативного резерва продолжают собираться до подтверждения передачи. Защитный
`pre-tool-use` остаётся у провайдера: события BB не могут его заменить.
Обёртка работает только с явно переданной командой и передаёт ей исходный
stdin при отсутствии действующей отметки. Отметку нельзя переносить между
машинами. Если BB не успеет отметить короткий первый ход, действует резервный
Stop. Отметка исчезает после завершения хода, отключения плагина или истечения срока.

Включение плагина не редактирует настройки Codex автоматически.
