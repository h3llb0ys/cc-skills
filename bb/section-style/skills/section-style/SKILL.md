---
name: section-style
description: Explain icons and heading colors supplied by the Section Style BB plugin.
---

Section Style decorates the existing standard Thread list. Open a project or
section heading menu → Оформление…; also available in the plugin's Settings page.
Choose an outline icon and a title color, save, cancel or reset.
It does not manage thread order, grouping, indentation, names, or directories.
It uses a content script because BB has no heading-decoration slot. For another
sidebar provider, use that provider's own appearance controls.
