# Diff Preview для BB

Показывает Git-диф при наведении на файл в стандартном списке **Changed files** над полем ввода. Превью поддерживает фокус с клавиатуры и закрывается по Esc. Клик по строке выполняет обычное действие BB.

[Установка и обновление из GitHub или локального клона](../README.md).

Настройки доступны на странице **Diff Preview** в **Settings → Installed plugins**.

- **Preview on hover** — включено.
- **Hover delay** — 500 мс по умолчанию, также доступны 250 и 800 мс.
- **Preview placement** — поверх списка рядом со строкой или за пределами списка.
- **Show line numbers** — включено.

Превью использует сравнение из списка BB. Если есть незакоммиченные изменения, оно показывает диф рабочей копии. Для закоммиченных изменений показывает диф ветки относительно выбранной базы. Для бинарных файлов, слишком больших патчей и недоступных данных в окне отображается статус.

Нужен включённый встроенный плагин Git. Diff Preview использует разметку его карточки **Changed files** и API для чтения дифа.

```sh
npm ci
npm run typecheck
npm test
npm run build
```
