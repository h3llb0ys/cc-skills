# Jira Thread Links

Локальный плагин BB для актуальных задач Jira в списке тредов.

- Одна задача: постоянно видимый кликабельный ключ справа от названия.
- Несколько: ключи с переносом под названием.
- Тултип: ключ и название; ссылка открывает Jira в новой вкладке.
- Над полем ввода: тот же набор кликабельных ключей Jira; без задач ряд скрыт.
- Меню треда → **Задачи Jira…**: изменить набор, убрать конкретную задачу или очистить поле.
- **Обновить названия из Jira** обновляет названия и адреса принудительно. Обычное чтение обновляет кеш старше часа; при недоступности Jira сохраняет прежние ярлыки.

## Автоматическая привязка

Плагин добавляет агенту инструмент `jira_thread_tasks` и правила анализа намерения пользователя. Агент читает текущий набор и применяет добавление, удаление или замену. Ссылки на связанные задачи, цитаты и примеры не устанавливают привязки. Чтение Jira само по себе ничего не меняет.

Инструкции/инструмент подключаются при следующем создании сессии провайдера; уже выполняющаяся сессия не меняется на лету. Старый тред может восстановить привязку при следующем рабочем запросе агенту из доступной истории, если привязки ещё не было. Простое открытие старого треда без запуска агента не анализирует историю. Семантический выбор делает агент, поэтому ручное исправление остаётся доступно.

`projectPrefixes` — JSON map ID проекта BB → префикс Jira. Короткий номер допускается только с настроенным префиксом; полный ключ можно указать в любом проекте. По умолчанию map пустая.

Наборы хранятся через KV BB по одному ключу на тред; KV сохраняется в базе BB. Ревизии и последовательная запись защищают ручные правки от устаревших параллельных вызовов. Пустая сохранённая привязка означает намеренное удаление и не восстанавливается из старых сообщений.

## Интеграция и ограничения

Нужен настроенный плагин `jira-boards`. Его RPC `issue` предоставляет ключ, заголовок и HTTPS URL; этот плагин не читает токен и не меняет Jira.

BB SDK 0.6.132 пока не предоставляет слот для метаданных справа от названия. Поэтому поддерживаемый `contentScripts` API добавляет собственные узлы в штатные строки через `data-sidebar-thread-id`, `data-sidebar-rename-row`, `.bb-thread-title`. На выгрузке удаляются узлы, классы, стили и наблюдатель. При смене разметки BB этот небольшой адаптер может потребовать обновления. Альтернативные списки без этих атрибутов не декорируются.

## Проверка и установка

```sh
cd ~/extra/cc-skills/bb/jira-thread-links
npm install --include=dev
npm test
npm run typecheck
bb plugin build
bb plugin install . --yes
```

Проверены unit/integration тесты набора и конкуренции, Jira RPC через официальный SDK test harness, DOM-поведение в jsdom. В работающем BB проверены одиночный ярлык, несколько ярлыков, тултипы/URL, меню редактора и удаление. Тестовые привязки убраны.

Скилл находится в [`skills/jira-thread-links`](../../skills/jira-thread-links/SKILL.md) репозитория и подключён в плагин симлинком, как у `mr-cycle`.

Плагин устанавливается из этого каталога. После изменения пути: `bb plugin install <новый путь> --yes`. Обновление: `git pull`, `npm install --include=dev`, `bb plugin build`, `bb plugin reload jira-thread-links`.
