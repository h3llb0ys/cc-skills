# Jira Thread Links Implementation Plan

**Goal:** Показывать актуальные задачи Jira: одну рядом с названием треда, несколько под названием; дать ручное управление и обновление агентом по намерению пользователя.

**Architecture:** Отдельный плагин, не меняющий установленные пакеты. Привязки в KV базе BB с версией для защиты ручных правок от устаревшего агента. Jira RPC существующего плагина предоставляет проверенные ключи, названия и URL. Агент получает инструмент чтения/изменения набора и правила; чтение Jira само по себе не меняет набор. UI читает данные пачкой и обновляется по realtime. Content script оформляет строки штатного sidebar через существующие data-атрибуты; полностью удаляет свои элементы при выгрузке.

**Tech Stack:** BB Plugin SDK 0.6.132, TypeScript, React, Zod, BB KV, node:test, jsdom.

1. tests/bindings.test.ts: сначала проверить нормализацию, операции набора и optimistic concurrency; lib/bindings.ts реализует хранилище.
2. tests/rows.test.ts: проверить один/несколько/ноль, безопасные ссылки, cleanup и повторное использование строк; lib/rows.ts добавляет только собственные DOM-узлы и классы.
3. server.ts: RPC, инструмент агента, пакетное чтение, кеш Jira, ручные изменения и realtime.
4. app.tsx: SDK overlay для чтения данных и редактора, действие меню; lib/rows.ts оформляет штатные строки.
5. skills/jira-thread-links/SKILL.md: правила актуальности, добавление/замена/удаление, голые номера только с настроенным префиксом, защита ручных правок.
6. Проверить тесты, typecheck, build; установить отдельный плагин и проверить live RPC и UI. Документировать ограничение DOM-интеграции и следующего запуска сессий для инструкций агента.
