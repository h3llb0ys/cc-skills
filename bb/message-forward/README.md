# Message Forward

Действие **«Переслать в чат…»** доступно у сообщений пользователя и LLM в основном
чате BB. Выберите **«Ссылка»** или **«Текст»** и кликните по чату. Плагин откроет
выбранный чат и допишет содержимое в конец черновика. Отправьте его обычной
кнопкой чата. При запуске из меню выделения режим «Текст» берёт выделенный фрагмент.

Чаты сгруппированы по проектам. Стрелка раскрывает подтреды, а поиск показывает
совпадения вместе с родительскими тредами. У подтреда из другого проекта
название проекта показано в той же строке.

На BB 0.50.1 действие показывается в ряду кнопок под сообщением и попадает в
меню `…`, когда в ряду не хватает места.

## Установка

Требуется BB 0.50.1 или новее.

```sh
bb plugin install git:https://github.com/h3llb0ys/cc-skills.git@main --subdirectory bb/message-forward
```

### Из локального клона

    cd ~/extra/cc-skills/bb/message-forward
    npm ci --include=dev
    npm run build
    bb plugin install .

Для проверки типов выполните `npm run typecheck`.
