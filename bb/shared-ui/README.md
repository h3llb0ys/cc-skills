# BB shared UI

Jira Thread Links, Section Style и Workspace Labels импортируют палитру из этого
каталога. Каждый плагин включает её в свой бандл при сборке BB.

Для локальных тестов и проверки типов сначала выполните `npm ci --prefix bb/shared-ui`
из корня репозитория и установите зависимости проверяемого плагина. При установке
плагина через BB отдельная установка зависимостей shared-ui не требуется.

`thread-row.ts` описывает общий формат разметки для компактных строк Section
Style. Jira Thread Links, GitLab MR и Workspace Tools публикуют метаданные,
которые уже загрузили для штатного списка.
