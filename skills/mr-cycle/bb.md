# Прогресс в bb

Цикл отмечает ход командой `bb mr-cycle`: владелец видит этапы, процент и проверки в интерфейсе bb.
Для всех вызовов ниже выбирай CLI приложения по абсолютному пути. В shell Cursor команда `bb`
может указывать на одноимённую утилиту из Homebrew. BB передаёт путь в `BB_CLI`, а локальная
установка приложения предоставляет `~/.bb/bin/bb`.

```bash
bb_cli="${BB_CLI:-$HOME/.bb/bin/bb}"
```

Задавай `bb_cli` в каждом новом вызове shell перед командой. Если команда учёта прогресса
завершилась ошибкой, сообщи об этом в чат и продолжи цикл.

| Когда | Команда |
|---|---|
| старт цикла — нового MR или повторного прогона | `"$bb_cli" mr-cycle start --title "$(git branch --show-current)"` — заменяет прошлый цикл треда |
| начало этапа N (9 — итоговый отчёт) | `"$bb_cli" mr-cycle stage N running` |
| конец этапа | `"$bb_cli" mr-cycle stage N done --note "<итог в 2–5 словах>"`, например «4 исправлено», «+7 кейсов» |
| этап не нужен | `"$bb_cli" mr-cycle stage N skipped --note "<причина>"` |
| возврат к этапу 7 | `"$bb_cli" mr-cycle stage 7 running` — этапы после него сбросятся сами |
| проход этапа 7 закончен | `"$bb_cli" mr-cycle sub 7 <bottom\|top\|mutation> done` |
| после каждого прогона проверки | `"$bb_cli" mr-cycle check <build\|vet\|lint\|unit\|integration> <ok\|fail>` |
