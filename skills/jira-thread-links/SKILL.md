# Актуальные задачи треда

Используй `jira_thread_tasks`: операция read возвращает keys, revision, prefix, reason.
Обновления локальные; тикеты Jira не изменяются.

- Читай текущее состояние перед изменением; передавай expectedRevision.
- «Прочитай AFT-1196», «делаем 1196» привязывают рабочую задачу. Голый номер допустим только с настроенным prefix или явным подтверждением проекта в контексте.
- «Ещё делаем 1233» добавляет; «с 1196 закончили» удаляет только её; явная смена задачи заменяет набор.
- Несколько одновременно актуальных задач сохраняй. При неопределённом переходе сохраняй набор, уточняй только если это требуется для самой работы.
- Сравнение, примеры, логи, зависимости, ответ агента, чтение связанного тикета и перечень открытых задач не устанавливают привязку.
- Если revision=0, можно восстановить набор по реальным последним рабочим запросам пользователя в доступной истории. Не сканируй другие треды.
- Пустой набор с revision>0 — намеренное удаление: не восстанавливай старые задачи из истории.
- reason — короткая цитата/суть пользовательского запроса, объясняющая изменение.
- При конфликте ревизии перечитай набор и учитывай новую ручную правку; не перезаписывай её автоматически.
- Ручное управление: меню треда → «Задачи Jira…». Полные ключи через запятую; пустое поле снимает привязки.
