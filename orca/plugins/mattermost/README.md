# Mattermost для Orca 1.4.278

Локальная правая панель: подписки на ветки/каналы, индивидуальные условия и интервал,
черновики, срок, пауза, ручная проверка, сводки и настройка сессионной cookie.
Ничего не публикует в Mattermost. «Оригинал» открывает исходную ссылку.

## Установка из каталога (macOS)

Нужны Python 3.10+ и установленная Orca с CLI `orca`.

```sh
cd ~/extra/cc-skills
python3 orca/plugins/mattermost/prepare.py
orca plugin validate orca/plugins/mattermost --json
orca plugin inspect orca/plugins/mattermost --json
```

В Settings → Plugins включи плагины, выбери установку из локального каталога и укажи
`~/extra/cc-skills/orca/plugins/mattermost`. Подтверди именно этот trusted worker:
он запускает Python/CLI с доступом твоего пользователя; отдельных host capabilities нет.
Панель: `orca plugin open local.mattermost --panel mattermost --json`.
Автоматическая или постоянная установка во время разработки не выполнялась.

`prepare.py` копирует канонические `skills/mattermost/scripts/*.py` в `runtime/` внутри
плагина. Orca копирует готовый каталог вместе с runtime: рабочие расписания используют
абсолютный путь к этой установленной копии `mm.py`, а не к dev-worktree. Не устанавливай
неподготовленный каталог. После обновления общего CLI снова запусти prepare и переустанови.
Существующие подписки подхватываются из общей SQLite; если их старый путь исчез,
приостанови и возобнови подписку — enable перепишет precheck и prompt на новый путь.
Удаление плагина само по себе не удаляет расписания: предварительно поставь подписки на паузу.

## Подключение и работа

В «Соединении» укажи HTTPS-адрес и значение заголовка Cookie из своей сессии Mattermost.
Cookie передаётся worker → Python через stdin, сохраняется общим CLI в локальном файле
с правами 0600 и не попадает в prompt, argv или логи плагина. Пустая cookie оставляет
сохранённую только для прежнего сервера. Настройка общая с BB и CLI.

В форме укажи ссылку и условие («Ждут моего ответа» или своё правило). Бот и чат
выбираются по названиям через Orca CLI; сохранённый выбор используется повторно.
Если найден единственный чат «Ответы на Q&A по сервисам» у magabot, он предлагается
по умолчанию. При неоднозначности требуется явный выбор. Интервал по умолчанию 10 минут.
После вставки ссылки выполняется preview без записи подписки: ссылка на ответ приводится
к корню ветки; совпадение ищется только для выбранных бота/чата и Orca platform.

Первый разбор: «Учесть открытые вопросы» сохраняет прежнее поведение; «Только новое»
сохраняет полный baseline перед созданием, включая канал, и не пропускает сообщения,
пришедшие после него. BB и существующие подписки сохраняют свои настройки.
Срок (сутки/неделя/без срока), локальный часовой пояс и черновик — в «Дополнительно».
Сменить чат текущего бота можно в редакторе: ID, история и cursor сохраняются, старые
receipts отзываются, конфликт с существующей подпиской отклоняется. Смена бота требует
новой подписки: её расписание принадлежит боту. Назначение хранится в watch, scheduler
prompt читает его по ID, поэтому при смене чата перепривязка расписания не нужна.

«Проверить сейчас» сначала делает принудительный tick и сохраняет batch, затем вызывает
`orca automations run` только при наличии работы. Сам Run now в Orca precheck обходит.
Тихая проверка не запускает агента. Повторный разбор ждёт окончания lease
(не меньше 15 минут), включая случай, когда CLI не подтвердил запуск из-за timeout. Чтение канала может продолжиться на следующем tick.
Пауза запрещает завершение уже выданного batch. Ошибка доставки сохраняет сводку во
«Входящих», без автоматического повторного отправления при неопределённом результате.

Статусы различают паузу, завершение, ожидание разбора, тихую проверку, ошибку и отсутствующее/
отключённое расписание. «Восстановить расписание» создаёт/обновляет только расписание данной
Orca-подписки. BB-записи скрыты и защищены проверкой platform внутри транзакции CLI.
Завершённую подписку можно удалить с подтверждением и создать заново; входящие сохранятся.
После ручной проверки панель обновляет только локальные статусы каждые 4 секунды до
завершения разбора, максимум 20 минут; таймер отключается при закрытии панели. Mattermost
этот таймер не опрашивает. Для остальных внешних изменений используй обновление списка.
Входящие показывают по 10 сводок с переходом к предыдущим страницам; превью каждого тела
и черновика ограничено 2000 символами до передачи панели. Копирование берёт полный
черновик из SQLite. «Последние сводки» возвращает на первую страницу.

SDK 1.4.278 не даёт panel clipboard API. Кнопка «Копировать черновик» вызывает trusted worker
и системный macOS `pbcopy` через stdin, без shell; исходный текст не используется как команда.
Настройка расписания идёт через общий CLI, поскольку host automation API не покрывает bot,
precheck и доставку в выбранный chat ID.

## Проверка без реальных данных

```sh
python3 -m unittest discover -s skills/mattermost/tests -q
orca plugin test orca/plugins/mattermost --json
orca plugin check orca/plugins/mattermost --json
orca plugin validate orca/plugins/mattermost --json
```

Python mock E2E проходит bridge → общий CLI → SQLite → подставленный scheduler:
создание, сохранённые подписки, check/quiet/busy, редактирование, пауза/возобновление,
ошибка запуска/доставки, inbox, копирование и защита BB с совпадающим chat ID.
Plugin tests проверяют нативную форму/кнопки и запуск реального Python bridge для отказа
неизвестной операции. Check использует только mock-ответы, не читает реальные подписки.

Для TypeScript после `orca plugin types ... --json` нужны TypeScript и `@types/node`;
добавь node к `--types`, а каталог пакетов к `--typeRoots` вместе с `.orca/types`.
Визуальный capture: `orca plugin shot orca/plugins/mattermost --scenario populated --json`
требует скрытого/минимизированного окна. На этапе разработки он был отказан из-за видимого окна;
визуальный QA скриншота не заявляется. Доступ к живому Mattermost, реальная доставка в бот,
установка из UI и реальный буфер обмена не проверялись; живые подписки не создавались.

Компактные действия используют native IconButton с label/tooltip и Row gap=xs.
SDK 1.4.278 не предоставляет Menu/Dropdown: «⋯ Действия» — доступный native Collapsible.
Входящие раскрывают сводку/черновик по запросу, preview ограничен; полный черновик
копируется из SQLite. Раскрытая сводка ограничена 16000 символами на поле.

После plugin update существующие расписания используют тот же установленный путь runtime.
Если Orca перенесла каталог плагина на другой путь, pause/resume перепривяжет precheck
и prompt. При смене чата в текущем боте это не требуется. Перед обновлением всегда prepare.
